# Local-First (Offline-Only) Mode

این برنامه به‌صورت کاملاً local-first اجرا می‌شود:

- **هیچ تماس شبکه‌ای** با Supabase در زمان اجرا انجام نمی‌گیرد.
- تمام داده‌ها (کاربران، نقش‌ها، رکوردهای سلامت، ارزیابی‌ها، آموزش‌ها و …) در **IndexedDB** مرورگر/Electron ذخیره می‌شوند.
- رمز عبور با **PBKDF2-SHA256 (250k iterations)** و salt تصادفی هَش می‌شود؛ خود رمز هرگز ذخیره نمی‌شود.
- ثبت‌نام و ورود از همان بار اول **بدون اینترنت** ممکن است.

## نخستین اجرا

1. در صفحه‌ی Auth روی «ثبت‌نام» کلیک کنید و یک حساب بسازید.
2. **اولین کاربر به‌صورت خودکار نقش `admin` می‌گیرد.**
3. ثبت‌نام عمومی پس از اولین کاربر **غیرفعال** می‌شود — کاربران بعدی فقط از طریق پنل «مدیریت کاربران» توسط ادمین/مدیر سیستم ساخته می‌شوند.

## مدیریت کاربران

ادمین در منوی «مدیریت کاربران» می‌تواند:
- کاربر جدید با ایمیل + رمز موقت + نقش بسازد.
- نقش کاربر را تغییر دهد.
- کاربر را غیرفعال/فعال کند.

نقش‌های پشتیبانی‌شده: `admin`, `safety_officer`, `supervisor`, `medical_officer`, `senior_manager`, `developer`, `viewer`.

## مهاجرت از Supabase

داده‌های قبلی Supabase یک‌بار به `public/seed/seed.json` صادر شده‌اند. در نخستین اجرای برنامه این داده‌ها به‌صورت خودکار به IndexedDB بارگذاری می‌شوند. کاربران auth قبلی فهرست می‌شوند ولی رمز عبور قابل بازیابی نیست — ادمین باید برای آنها رمز موقت تعیین کند.

## نصب روی سرور (حالت چندکاربره)

اگر بعداً خواستید برنامه روی یک سرور نصب و بین چند کاربر همگام شود، یک sync adapter اختیاری در `src/lib/syncManager.ts` آماده‌ی توسعه است. در حالت پیش‌فرض هیچ همگام‌سازی شبکه‌ای انجام نمی‌شود.

## هوش مصنوعی آفلاین

برای استفاده از AI Chat بدون اینترنت، یک نسخه‌ی Ollama روی دستگاه نصب کنید:

```bash
ollama pull llama3.1
ollama serve
```

سپس در تنظیمات چت، endpoint را روی `http://localhost:11434` بگذارید.
