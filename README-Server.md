# نسخه سرور داخلی شرکت

این پوشه یک سرور Node ساده با پایگاه‌داده SQLite است که فقط داخل شبکه شرکت اجرا می‌شود و داده‌های HSE را بین تمام سیستم‌های کلاینت به اشتراک می‌گذارد.

## نصب

```bash
cd server
npm install
npm start        # http://0.0.0.0:4000
```

فایل داده در `server/hse.db` ساخته می‌شود (SQLite تک‌فایل). برای نصب پایدار روی ویندوز، می‌توانید از `node-windows` یا `nssm` استفاده کنید تا سرور به‌عنوان سرویس اجرا شود.

## اتصال کلاینت‌ها

در هر سیستم کاربر (نسخه دسکتاپ یا مرورگر)، متغیر محیطی زیر را قبل از build تنظیم کنید:

```
VITE_SERVER_URL=http://10.0.0.5:4000
```

(به‌جای `10.0.0.5:4000` آدرس واقعی سرور داخل شبکه را بگذارید.)

وقتی این متغیر ست شده باشد، تمام تماس‌های `db.from(...)` به‌جای IndexedDB به این سرور می‌روند و داده‌ها بین کلاینت‌ها به اشتراک گذاشته می‌شوند. در نبود شبکه، آخرین داده‌های cache شده در IndexedDB نمایش داده می‌شوند.

## پورت و امنیت

- به‌طور پیش‌فرض روی پورت 4000 گوش می‌دهد. با `PORT=8080 npm start` عوض کنید.
- **این سرور برای شبکه داخلی طراحی شده است.** پیش از انتشار روی اینترنت، حداقل یک reverse proxy با HTTPS و احراز هویت اضافه کنید.

## پشتیبان‌گیری

فقط فایل `hse.db` را کپی کنید. SQLite در حالت WAL نیز فایل‌های `hse.db-wal` و `hse.db-shm` را در کنار آن نگه می‌دارد.
